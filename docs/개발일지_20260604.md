### 2-3. 스타일링 (`assets/css/style.css`)
- CSS 변수 기반 설계 — 테마 전환 시 변수만 교체
- 반응형 레이아웃 (Flexbox + CSS Grid)
- 스크롤 페이드업 애니메이션 (IntersectionObserver)
- 고정 네비게이션 바 (backdrop-filter blur 처리)

### 2-4. 컬러 테마 시스템 (`assets/css/themes/`)
5종 테마 파일 독립 관리:

| 파일 | 주컬러 | 보조컬러 |
|------|--------|----------|
| `theme-green.css` ★기본 | 다크 그린 `#52b788` | 스카이블루 `#56cfe1` |
| `theme-blue.css` | 다크 블루 `#6ea8fe` | 페리윙클 `#a8c7fa` |
| `theme-purple.css` | 다크 퍼플 `#b39ddb` | 라벤더 `#d4b8f5` |
| `theme-teal.css` | 다크 틸 `#4ecdc4` | 아쿠아 `#72efdd` |
| `theme-rose.css` | 다크 로즈 `#e88fa9` | 블러쉬 `#f4b8cc` |

- 각 테마: 다크 모드 / 라이트 모드 변수 분리 정의
- `body.light-mode` 클래스 토글 방식으로 전환
- `localStorage`로 선택값 영구 저장

### 2-5. JavaScript 기능 (`assets/js/main.js`)

| 기능 | 구현 방식 |
|------|-----------|
| 파티클 배경 | Canvas API — 72개 점, 인접 선 연결, 테마 색상 연동 |
| 타이핑 효과 | 재귀 setTimeout — 3개 문구 순환 |
| GSAP MotionPath | S커브 path를 따라 rect 순환 (18초 주기) |
| 팔레트 스위처 | `<link id="theme-css">` href 교체 방식 |
| 다크/라이트 토글 | `body.light-mode` 클래스 추가·제거 |
| 햄버거 메뉴 | 모바일 전용 풀스크린 슬라이드 네비게이션 |
| 스크롤 페이드업 | IntersectionObserver |
| 활성 네비 링크 | scroll 이벤트 기반 섹션 감지 |

## 3. 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 클론 폴더명 오류 | Bash에서 Windows 경로 역슬래시 처리 오류 | PowerShell로 폴더명 수정 |
| git push 거절 | 원격에 로컬에 없는 커밋 존재 | `git pull --no-rebase` 후 재푸시 |
| GitHub Pages 404 | Pages 설정 미저장 상태 | 설정 페이지에서 Save 재클릭 |
| Canvas 한글 폰트 | Web Font가 canvas에 즉시 적용 안 됨 | `document.fonts.ready` 대기 후 렌더링 |
| 파티클 색상 미연동 | 테마 전환 시 canvas 색 미갱신 | `themeCss.onload` 콜백으로 CSS 변수 재조회 |
