## 2. 기술 스택 평가

### 2-1. 아키텍처 선택
- **순수 HTML/CSS/JS 정적 사이트** 채택
- 평가: ★★★★★
  - 빌드 도구·패키지 관리 없이 GitHub Pages 즉시 배포 가능
  - 로딩 속도 빠름 (번들링 오버헤드 없음)
  - 유지보수 간단 — 파일 수정 후 푸시만으로 배포

### 2-2. CSS 설계
- **CSS 변수(Custom Properties) 기반 테마 시스템** 채택
- 평가: ★★★★★
  - `<link>` href 교체만으로 테마 전환 — 런타임 JS 로직 최소화
  - 다크/라이트 모드는 `body.light-mode` 클래스 하나로 전환
  - 변수 계층 구조: `--color-accent`, `--glow-sm`, `--gradient-accent` 등 역할별 분리

### 2-3. 애니메이션 구현
| 기능 | 평가 | 코멘트 |
|------|------|--------|
| Canvas 파티클 | ★★★★☆ | `requestAnimationFrame` 사용으로 성능 양호. 모바일에서 배터리 소모 고려 필요 |
| GSAP MotionPath | ★★★★★ | CDN 로드 방식으로 번들 크기 영향 없음 |
| 타이핑 효과 | ★★★★★ | 순수 JS `setTimeout` 재귀 — 경량 구현 |
| 스크롤 페이드업 | ★★★★★ | `IntersectionObserver` — 스크롤 이벤트보다 성능 우수 |

### 2-4. 반응형 대응
- 평가: ★★★★☆
  - 햄버거 메뉴, 컬럼 전환, SVG 숨김 처리 등 주요 모바일 이슈 해결
